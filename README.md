# 強さの数字（tsuyosa-suji）

2人の架空の選手のレーティング（強さの数字）を見て、Aの「見込み」か、勝ち・負け・引き分けのあとにAの点がどれだけ動くかを当てる1日5問の学習ゲーム。点の動きに正解したら、相手（B）の点がどう動くかも選ぶ。K の値や400点の決まりなどの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/tsuyosa-suji/>

- 中身は FIDE（国際チェス連盟）の「FIDE Rating Regulations」<https://handbook.fide.com/chapter/B022024> の見込みの表（8.1.2）と、点の動き・K・400点・丸めの決まり（8.3）、一覧の決まり（7.2.1）に書いてあることだけです。
- 選手と大会は架空で、本物の選手の記録ではありません。お金や賭けとは関係ありません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
